# 第一部分 SCIcoRS 仿真内核避坑清单

## 1 浮点精度不统一问题

### 风险表现

跨模块混用`f32/f64`造成累积误差；浮点直接用`==`等值判断逻辑失效；多场耦合精度层级不一致，求解发散；大小尺度数值出现溢出 / 下溢。

### 根源

硬编码浮点类型，无全局统一精度定义；缺少统一对比阈值 epsilon；仿真内核与可视化层精度配置割裂。

### 解决方案

1. 全局定义`pub type Real = f64;`唯一实数类型，禁止直接书写 f32/f64；

2. 全局统一精度阈值常量，所有浮点数比较基于阈值判断；

3. 仅修改一处类型别名即可全局切换单 / 双精度。

## 2 时序系统混乱问题

### 风险表现

连续动力学与离散逻辑时序偏移；快慢多速率仿真数据错位；定步长 / 变步长混用丢失触发事件；时间轴缩放错误结果失真。

### 根源

缺少中心化时间上下文管理；无多速率任务调度器；求解器步长控制规则不统一；离散事件时间戳无校验。

### 解决方案

1. 全局唯一仿真时间轴上下文；

2. 分离快慢任务独立调度队列；

3. 约束全部求解器步长管理规则；

4. 跨领域数据交互强制时间戳同步校验。

## 3 代数环迭代卡死、不收敛问题

### 风险表现

闭环反馈系统无限循环迭代；代数方程组求解发散、程序 panic；耦合反馈计算效率极低。

### 根源

无代数环自动检测逻辑；闭环端口直接互相引用无缓冲；缺少迭代上限与松弛因子。

### 解决方案

1. 仿真初始化阶段自动检测并标记代数环；

2. 增加中间缓冲层打断端口直接循环依赖；

3. 配置迭代次数上限、收敛判定阈值、松弛迭代算法。

## 4 内存持续暴涨溢出问题

### 风险表现

长时间仿真内存占用持续走高；三维场网格数据内存开销巨大；探针 Recorder 无限存储历史波形。

### 根源

无历史数据采样、淘汰机制；稀疏场数据采用稠密数组存储；数据记录无容量上限。

### 解决方案

1. 场数据按需使用稀疏数组结构；

2. 配置 Recorder 最大存储长度，支持超大数据流式写入磁盘；

3. 严格管控临时计算变量生命周期，减少内存碎片。

## 5 刚性系统数值不稳定问题

### 风险表现

计算结果出现 NaN、Inf；刚性电路 / 动力学系统使用普通 RK4 求解完全失效；步长不合理动态响应畸变。

### 根源

求解器与方程特性不匹配；固定步长无法自适应动态变化；差分、导数计算公式错误。

### 解决方案

1. 区分刚性 / 非刚性方程，匹配 BDF、RK45 等专用求解器；

2. 启用自适应变步长求解；

3. 增加数值发散实时监控告警。

## 6 物理单位体系错乱问题

### 风险表现

仿真结果数量级偏差上千倍，极难排查；跨物理场耦合参数单位冲突；摄氏度 / 开尔文、秒 / 毫秒混用计算错误。

### 根源

无统一单位转换模块；参数入参缺少单位合法性校验；物理量无量纲硬编码。

### 解决方案

1. 内置枚举式物理量类型 \+ 自动换算工具；

2. 所有模块入参强制单位校验；

3. 禁止裸写无量纲物理常数。

## 7 全局状态不可控问题

### 风险表现

仿真结果无法复现；多线程计算出现数据竞争崩溃；快照回滚功能状态残缺。

### 根源

模块间可变状态随意引用；共享变量无线程安全保护；快照未完整捕获全部运行状态。

### 解决方案

1. 封装仿真状态，限制外部可变访问权限；

2. 依托 Rust 所有权机制 \+ 同步原语处理并发状态；

3. 快照功能一次性完整拷贝全部状态数据。

## 8 零交叉、事件触发丢失问题

### 风险表现

开关动作、阈值判定、碰撞检测经常性漏触发；离散事件执行顺序错乱。

### 根源

仿真步长跳过临界交叉点；连续变量无专门过零检测；事件队列无序、优先级缺失。

### 解决方案

1. 关键变量添加专用零交叉检测算法；

2. 触发点附近自动加密计算步长；

3. 构建带优先级的有序事件调度队列。

## 9 线性代数运算隐患

### 风险表现

奇异矩阵求逆直接程序崩溃；大规模矩阵运算速度极慢；混合浮点类型精度损耗。

### 根源

矩阵求逆前未判断奇异性；大规模场运算使用稠密矩阵；Real 类型混用原生浮点。

### 解决方案

1. 矩阵运算前增加条件数、奇异性检查；

2. 大规模稀疏计算采用稀疏矩阵结构；

3. 全部线性代数计算统一 Real 类型；

4. 根据场景选择 ndarray/nalgebra/faer 最优后端。

## 10 多物理场耦合兼容问题

### 风险表现

电 \- 热 \- 力 \- 流模块数据无法互通；网格结构不一致无法数据映射；时间尺度差距过大耦合计算阻塞。

### 根源

各物理域数据结构不统一；缺少网格插值映射工具；无跨尺度数值适配逻辑。

### 解决方案

1. 定义全局标准化耦合数据结构；

2. 开发场数据插值、网格重采样模块；

3. 针对超大时间量级差设计分层耦合时序。

## 11 API 过度抽象工程化问题

### 风险表现

接口调用复杂晦涩、上手成本极高；泛型 trait 滥用代码可读性差；模块耦合严重后期难以迭代。

### 根源

片面追求通用化设计；边界划分模糊；核心功能被多层包装。

### 解决方案

1. 核心 API 保持简洁，减少不必要泛型抽象；

2. 明确模块职责边界，禁止跨模块内部依赖；

3. 优先保证可维护性，弱化过度通用性。

## 12 数学运算边界缺失检查

### 风险表现

除零、负数开根号、log \(0\) 等非法运算触发 panic；数组索引越界崩溃；密度、压力等物理量出现负值非法值。

### 根源

缺少入参合法性校验；未对特殊数学运算做异常兜底；直接使用原生数组下标访问。

### 解决方案

1. 所有外部入参做范围校验；

2. 特殊数学计算增加分支保护，返回 Result 错误类型；

3. 统一使用 Rust 安全索引访问方式。

# 第二部分 自研 3D BREP 三维几何建模库避坑清单

## 1 浮点容差体系缺陷

### 风险表现

本该重合的点判定分离、闭合轮廓识别为开口；模型单位切换（mm/m）几何缝合异常；微小浮点噪声破坏模型拓扑有效性。

### 根源

无全局统一几何容差 Tolerance；直接用 == 对比三维点坐标；容差数值固定，不随模型尺寸缩放。

### 解决方案

1. 全局唯一几何公差配置项，一处修改全局生效；

2. 点、边、面重合判定全部基于距离容差；

3. 根据模型包围盒尺寸动态自适应公差大小。

## 2 BREP 拓扑与几何数据脱节

### 风险表现

曲面裁剪后破面；一条边被三个及以上面共享（非流形）；边曲线和拓扑参数域不匹配；共享顶点重复创建，布尔运算失败。

### 根源

修改几何曲线曲面后，未同步更新拓扑结构；缺少非流形拓扑自动检查机制；拓扑元素引用副本而非唯一实例。

### 解决方案

1. 几何变更必须联动拓扑结构刷新；

2. 模型构建完成自动校验流形合法性；

3. 顶点、边全局唯一复用，禁止重复实例化。

## 3 曲线曲面参数化缺陷

### 风险表现

球面、圆锥极点处法向计算 NaN；曲面偏移、扫掠造型扭曲；曲面内外法向朝向混乱。

### 根源

未处理几何奇异点位；参数区间混用归一化 \[0,1\] 与实际弧长；曲线方向、面朝向无统一标记。

### 解决方案

1. 针对极点、退化点单独算法分支；

2. 全局标准化参数域规则；

3. 实体统一拓扑朝向规则，自动修正法向。

## 4 布尔运算健壮性差

### 风险表现

共面形体布尔运算直接失败；相交线断裂不闭合；运算后产生大量碎小面、极短边；模型自相交仍执行布尔计算。

### 根源

交线求解算法鲁棒性不足；无前置自相交检测；微小几何碎片无自动清理逻辑。

### 解决方案

1. 布尔前置执行自相交、共面判断；

2. 交线分段闭合校验；

3. 自动过滤低于公差的细碎几何元素。

## 5 缝合拓扑重建异常

### 风险表现

临近点错误合并、该缝合边界无法闭合；封闭壳体体积计算结果错误。

### 根源

点合并阈值不合理；拓扑环顺序错乱；拓扑朝向不一致。

### 解决方案

1. 分场景配置点边缝合阈值；

2. 重建壳体时强制边界环有序化；

3. 一致性检查拓扑方向。

## 6 索引内存稳定性问题

### 风险表现

删除顶点 / 边后索引越界；几何更新后缓存数据陈旧；频繁编辑模型性能开销巨大。

### 根源

采用硬索引存储拓扑关联；几何计算结果无缓存策略；每次编辑全量重建拓扑。

### 解决方案

1. 使用句柄式弱引用代替裸下标索引；

2. 增加计算结果缓存，设置失效刷新机制；

3. 实现增量拓扑更新，避免全局重算。

## 7 退化几何算法崩溃

### 风险表现

三点共线、四点共面时求交投影出错；切线、法线计算出现除零错误。

### 根源

几何算法仅考虑理想常规形态，无退化分支处理。

### 解决方案

所有几何计算前置退化特征判断，返回 Option/Result 容错。

## 8 性能瓶颈问题

### 风险表现

大型模型遍历查询 O \(n²\) 极慢；重复重复计算曲线曲面点值；无分级渲染 LOD。

### 根源

未使用 AABB 包围盒、八叉树空间加速结构；无计算缓存机制。

### 解决方案

1. 几何元素绑定包围盒加速查询；

2. 高频求值结果缓存复用；

3. 大规模网格提供多级精度 LOD 方案。

## 9 模型导入导出互操作问题

### 风险表现

STEP/IGES 导入模型拓扑破碎、精度丢失；序列化模型无法正常加载。

### 根源

第三方格式公差体系与自研内核不兼容；拓扑结构序列化逻辑不全。

### 解决方案

1. 导入后执行拓扑修复与缝合校验；

2. 完整实现 BREP 结构序列化 / 反序列化逻辑。

## 10 内部结构暴露导致非法模型

### 风险表现

外部代码随意修改拓扑字段，产生非法几何体；错误逐层传递，难以定位根源。

### 根源

结构体成员 pub 全部公开；缺少模型不变量检查。

### 解决方案

1. 私有化内部拓扑字段，仅通过 API 修改；

2. 每次几何编辑后自动执行合法性自检。

# 整体通用避坑总原则

1. **统一先行**：精度、容差、单位、时间轴四大全局配置集中定义，一处修改全库生效；

2. **防御式编程**：所有数值计算、几何运算、外部输入增加边界异常处理，杜绝直接 panic；

3. **数据解耦**：仿真层仅输出标准化数值数据集，几何库、可视化库单向消费数据，双向无强依赖；

4. **不变量校验**：仿真每一步迭代、几何每一次编辑后，自动校验结构合法性，早报错早修复；

5. **克制抽象**：底层核心逻辑优先稳定性、可读性，避免过度泛型设计增加维护成本。
