| `src/domains/tcad/bjt.rs` | Ebers-Moll BJT model (forward/reverse active), Early effect, small-signal, BjtBlock | 13 tests |

### Key Models

- **MOSFET Level 1**: β = KP·W/L, cutoff(Id=0), triode(β·(Veff-Vds/2)·Vds·(1+λ·Vds)), saturation(0.5·β·Veff²·(1+λ·Vds))
- **BJT Ebers-Moll**: Icc = Is·(exp(Vbe/(NF·Vt))-1), Iec = Is·(exp(Vbc/(NR·Vt))-1), Ic = Icc - Iec·(1+1/BR)
- **Diffusion**: Gaussian C(x,t) = N0/√(4πDt)·exp(-x²/(4Dt)), corrected normalization
- **Deal-Grove**: xox² + A·xox = B·t with temperature-dependent rate constants

- **16-bit RISC-like ISA**: 8 instructions (ADD, SUB, AND, OR, LW, SW, BEQ, ADDI)
- **5-stage pipeline**: IF→ID→EX→MEM→WB with pipeline drain on HALT
- **exec_one()**: direct instruction execution (bypass pipeline) for testing
- **Pipelining uses 5-bit immediates** to avoid field overlap in encoding
