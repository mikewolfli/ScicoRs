## 三、新增：CPU / GPU 专属自适应计算后端（核心需求）

### 新模块 `core/compute/backend.rs`（统一计算平台扩展）
- **`BackendKind`**：`Serial` / `CpuParallel`(rayon) / `Gpu`。
- **`ComputeConfig`**：`parallel_threshold`(默认 4096 工作单元)、`gpu_threshold`(默认 262144)、`force` 强制覆盖。
- **`GpuBackend` trait**：可插拔 GPU 运行库接口（`mat_mul/elementwise_add/axpy/dot/sum`），
  注册后自动用于大负载；无 GPU/不可用时透明回退 CPU —— 结果与 CPU 完全一致。
- **`AdaptiveCompute` 调度器**：按工作单元数自动选择 Serial → CpuParallel → Gpu；
  `set_gpu_backend/clear_gpu_backend/describe` 可观测。
- **自适应原语**：`mat_mul`、`elementwise_add`、`axpy`、`dot`、`sum`、`map_vec`。
- **全局便捷 API**：`global()`、`adaptive_mat_mul/add/axpy/dot`，已在 `lib.rs` 重导出。
- **集成点**：`matrix::par_mat_mul` 改为委托自适应调度器（消除重复阈值逻辑，单一事实来源）。

### 测试（11 个）
- 后端命名 / 小负载→Serial / 大负载→CpuParallel；
- 注册 GPU 后大负载→Gpu、小负载仍 Serial、未注册→回退 CpuParallel；
- Serial/CpuParallel/Gpu 三路结果数值一致（mat_mul、elementwise、dot、axpy、sum）；
- 强制覆盖、长度不匹配错误、全局便捷函数。

> 说明：GPU 路径为可插拔 trait + 真实调度/回退逻辑（CPU 自适应路径已真实生效）；真实 GPU 运行时
> （wgpu/OpenCL/CUDA）可在不改调用点的情况下按 `GpuBackend` 实现接入。测试使用 mock GPU 后端
> 验证调度与结果等价性，符合 principle.md「可观测、可验证」要求。
