## Round 2: Phase 16 Implementation — Molecular Dynamics & Biomolecular Simulation

### New Files Created

| File | Contents | Tests |
|------|----------|-------|
| `src/domains/molbio/mod.rs` | Module interface + re-exports | — |
| `src/domains/molbio/physics.rs` | Physical constants, element mass table, bond parameters | 6 tests |
| `src/domains/molbio/molecule.rs` | Atom, Bond, Residue, Molecule, PDB I/O | 10 tests |
| `src/domains/molbio/forcefield.rs` | HarmonicBond, HarmonicAngle, PeriodicDihedral, LennardJones, CoulombPotential, ForceField, Vec3 | 14 tests |
| `src/domains/molbio/dynamics.rs` | MolecularDynamics (Velocity Verlet, Langevin), EnergyMinimizer | 8 tests |
| `src/domains/molbio/docking.rs` | Simplified docking score function | 3 tests |
| `src/domains/molbio/analysis.rs` | RMSD, Rg, MSD, dihedral angle, hydrogen bond detection, SAS | 6 tests |

### Key Design Decisions

1. **Vec3 in forcefield.rs** — A lightweight 3D vector type used internally by molbio for molecular coordinates. Implements `From<Coord3D>` and `From<Vec3> for Coord3D` for interop with `core::coord`.

2. **ForceField architecture** — Each energy term is a separate struct implementing simple `energy()` and `force()` methods. `ForceField` aggregates them with atom index mappings. This avoids a complex inheritance hierarchy while remaining extensible.

3. **Molecule** — Supports building from scratch (add_atom, add_bond) and from simplified PDB-format lines. Includes factory methods for standard amino acids (alanine) and DNA short chains.

4. **MolecularDynamics** — Implements velocity Verlet integration as the primary integrator. Energy conservation checked via test. Langevin dynamics with implicit solvent friction. Berendsen thermostat for temperature coupling.

5. **EnergyMinimizer** — Both steepest descent and conjugate gradient methods. Convergence checked via gradient norm.

## Round 3: Phase 17 Implementation — Cell Culture & Tissue Growth

### New Files Created

| File | Contents | Tests |
|------|----------|-------|
| `src/domains/cellbio/mod.rs` | Module interface + re-exports | — |
| `src/domains/cellbio/physics.rs` | Biophysical constants, MediumProperty functions | 4 tests |
| `src/domains/cellbio/cell_model.rs` | Cell, CellPopulation, CellState | 8 tests |
| `src/domains/cellbio/media.rs` | CultureMedia, MediumComponent, standard media recipes | 6 tests |
| `src/domains/cellbio/growth.rs` | GridModel (3D lattice), reaction-diffusion, tissue morphology | 6 tests |
| `src/domains/cellbio/bioreactor.rs` | Bioreactor (batch/fed-batch/continuous/perfusion) | 5 tests |
| `src/domains/cellbio/analysis.rs` | Growth curve, Monod kinetics, Michaelis-Menten, viability | 4 tests |

### Key Design Decisions

1. **CellState** — A 10-state enum covering the full cell lifecycle (G1/S/G2/M/Quiescent/Apoptotic/Necrotic/Adherent/Migrating). The `CellPopulation::update()` method advances each cell based on local conditions.

2. **GridModel** — A 3D lattice model for reaction-diffusion simulation. Uses explicit Euler + central difference for the diffusion equation. Tracks local concentrations of nutrients/O2/pH/ECM per grid cell. Integrated with CellPopulation for spatial cell growth simulation.

3. **Bioreactor** — Supports 4 operation modes: batch, fed-batch (constant feed rate), continuous (dilution rate), and perfusion. Includes basic pH and DO control loops (proportional).

4. **CultureMedia** — Default recipes DMEM high-glucose and RPMI-1640. Dynamic pH calculation based on CO₂/bicarbonate buffer. Temperature-dependent diffusion and solubility.

5. **Monod + Michaelis-Menten kinetics** — Standard bioprocess models for specific growth rate and substrate uptake, integrated with the analysis module.
