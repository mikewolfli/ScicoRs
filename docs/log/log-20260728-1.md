### Key Design Decisions

1. **All blocks implement the `Block` trait** — they have ports (input/output), implement init/output/derivative/update, and are fully compatible with Diagram/SimEngine.

2. **Signal sources** produce deterministic outputs based on `current_time`:
   - SineSource uses `amplitude * sin(2π·f·t + phase) + offset`
   - SquareSource uses duty cycle for high/low ratio
   - StepSource has zero-crossing at step_time
   - NoiseSource uses LCG for deterministic pseudo-random + Box-Muller for Gaussian

3. **Math blocks** read from input ports and write to output ports each `output()` call:
   - Divider has epsilon zero-guard to prevent division by zero / NaN
   - TrigFunction returns f64::NEG_INFINITY for domain errors (log of negative)

4. **Continuous control** blocks declare state via `state_declaration()`:
   - Integrator declares continuous state, derivative returns input value
   - TransferFunction uses controllable canonical form (n state variables for nth-order)
   - StateSpaceSystem implements general `dx = Ax + Bu; y = Cx + Du`
   - PIDController has anti-windup via output clamping

5. **Sink blocks** are passive — they record/capture data during `update()`:
   - Scope uses ring buffer of fixed capacity
   - DataRecorder appends to Vec with optional max limit
   - ChartBuffer accumulates (time, value) pairs

## Round 3: Database System Implementation (Phase 12/Roadmap 阶段12)

### Dependency Added
- `rusqlite` v0.31 with `bundled` feature (compiles SQLite from source, no system dep needed)

### File Replaced
`src/db/mod.rs` — from placeholder comment to full implementation (~1100 lines)

### Architecture
```
LibraryManager         — High-level API: search, import, list, save, remove
├── LibraryDb          — SQLite index (WAL mode, FTS5 full-text search)
│   ├── Schema: libraries, entry_params, entry_tags, libraries_fts
│   ├── CRUD: upsert_entry, get_entry, delete_entry, search, list_category
│   └── PRAGMA: WAL + NORMAL sync + 8MB cache + memory temp + 256MB mmap
├── TomlLoader         — Loads library entries from resources/data/*.toml files
├── LibraryEntry       — Generic entry: id, name, category, parameters, tags
├── LibraryCategory    — 15 categories matching roadmap (Material..SemiconductorProcess)
└── load_sample_entries() — 12 built-in sample entries for demo/testing
```

### Schema Design
- `libraries` — main table with id, name, category, description, version, source
- `entry_params` — key-value parameter storage (supports f64, string, etc.)
- `entry_tags` — tag-based filtering
- `libraries_fts` — FTS5 virtual table for full-text search across name/desc/tags
- All queries use prepared statements; no SQL injection vector

### Sample Data Included
- Materials: Copper, Silicon, Aluminum
- Celestial: Earth, Sun
- Electrical: Resistor, Capacitor
- Logic gate: 74LS00 Quad NAND
- Fluids: Water, Air
