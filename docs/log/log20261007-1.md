## 1. 阶段 35 — 稀疏线性代数与稳健数值计算（P0）

### 1.1 新增模块（原则 1：功能文件夹 + mod.rs 只放接口）

```
src/core/compute/sparse/
  mod.rs            — 模块聚合与受控重导出
  matrix.rs         — COO/CSR/CSC、校验构造、格式互转（894 行）
  operations.rs     — SpMV、稀疏加减乘、转置、子矩阵选择（383 行）
  iterative.rs      — CG / MINRES / GMRES(m) / BiCGSTAB + 矩阵自由算子（1045 行）
  preconditioner.rs — Jacobi / 对角缩放（行 & 对称）/ ILU(0)（约 500 行）
  diagnostics.rs    — 迭代统计、停止原因、条件数估计（277 行）
src/core/compute/least_squares.rs — QR / SVD 最小二乘、伪逆、秩诊断（589 行）
```

### 1.2 行为实现要点（对应 blue13 §3.2）

- **构造校验**：拒绝越界索引、NaN/Inf；重复坐标在转 CSR/CSC 时按标准对称装配约定**求和**。
- **结构与数值分离**：CSR/CSC 暴露指针/索引/值三数组；`eliminate_zeros()` 显式清除存零。
- **Krylov 求解器**：CG（仅 SPD，非对称直接报 `Unsupported`，**不静默退化**）、
  MINRES（对称不定，Paige–Saunders 递推）、GMRES(m)（重启 + CGS2 重正交）、BiCGSTAB。
  全部返回 `KrylovSolution { x, stats }`；达到迭代上限显式报 `MaxIterationsReached`，**绝不标为收敛**。
- **预条件器**：Jacobi（零对角报错）、`DiagonalScaling`（行缩放 + **对称缩放** D·A·D）、
  ILU(0)（零主元报错）。`Preconditioner` trait 统一。
- **矩阵自由算子**：`LinearOperator` trait（apply/apply_transpose/diagonal），已为 CSR 实现。
- **对角缩放求解**：`cg_with_scaling` —— 对称均衡后 CG，**参考残差始终按原系统重算并报告**
  （避免把缩放后残差误当原系统残差，对应 blue13 §3.2 的显式要求）。
- **最小二乘**：`solve_qr`（Householder + 列主元，秩亏拒绝并指向 SVD）、`solve_svd`（单边 Jacobi SVD +
  截断，覆盖超定/欠定/秩亏，返回最小范数解）、`pseudo_inverse`。**不默认构造正规方程**。

### 1.3 验证证据（原则第 18 条）

`cargo test --lib sparse` → 47 passed；`cargo test --lib least_squares` → 9 passed。
覆盖：SPD/对称不定/非对称/奇异/近奇异/空系统；迭代上限非收敛；预条件不改解；秩亏/欠定最小范数；
对称均衡保持对称性；`cg_with_scaling` 报告原系统残差。

### 1.4 修复的真实缺陷（诚实记录）

1. MINRES 首版 Givens 递推与方向向量序号有误（实测解 0.91≠1.0）→ 重写为 Paige–Saunders 标准递推。
2. `cg_with_scaling` 首版用**行**缩放，破坏对称性导致 CG 直接报错 → 改为对称缩放 D·A·D。

## 4. 阶段 38 — 可复现执行、检查点与弹性任务调度（P1）

```
src/runtime/checkpoint/
  format.rs        — 版本化清单、原子且崩溃安全的写入、F(N)V 哈希
  snapshot.rs      — 状态/事件队列/RNG/记录器快照（紧凑二进制编解码）
  compatibility.rs — 模型/求解器/插件版本兼容策略
  manager.rs       — CheckpointStore 门面 + RunOutcome 六态分类
  integration_tests.rs — 真实 SimEngine 端到端断点续跑
src/runtime/execution/
  cancellation.rs  — 协作式取消令牌（跨线程可见）
  resources.rs     — CPU/内存/并发预算 + RAII 租约
  retry.rs         — 失败分类 + 指数退避，仅重试瞬态失败
```

- **崩溃安全**：写入 `<dir>.part` → 暂存目录；`dir`→`<dir>.old` → 暂存→`dir`；`load_checkpoint`
  在 `dir` 缺失时**回退读 `<dir>.old`**，任意崩溃点都不丢失最后一个有效检查点；写入前先恢复孤儿备份。
- **不兼容拒绝**：签名不匹配返回差异列表，绝不静默丢弃求解器历史/事件后声称续跑成功。
- **六态结束**：正常/取消/资源限制/数值失败/I-O 失败/超时，仅“正常”算成功。
- **重试**：仅 `Transient`/`ResourceExhausted` 可重试；输入错误与数值发散**绝不重试**。

验证：`cargo test --lib checkpoint` → 32 passed；`cargo test --lib execution` → 17 passed。
关键端到端测试 `checkpoint_resume_matches_uninterrupted_run`：真实 `SimEngine` 跑一遍不中断，再跑一遍
中途存档→销毁→新引擎恢复→跑完，断言**最终时间/步数/连续状态与不中断运行完全一致**。
另含崩溃窗口恢复、备份路径不碰撞、大载荷上限、损坏检测、未来 schema 拒绝、插件废弃通知。
