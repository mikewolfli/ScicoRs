## Architecture Refactoring — Module Restructuring

Following roadmap analysis, restructured project into 7-layer architecture:

### Before (flat in core/)
```
src/core/        — 17 mixed files (data model + runtime + everything)
```

### After (layered)
```
src/
  lib.rs               — Root module + re-exports
  core/                — Layer 1: Data model (14 files, unchanged)
    mod.rs, types.rs, block.rs, port.rs, link.rs, diagram.rs, ...
    coord/             — [empty] Phase 10 placeholder
    units/             — [empty] Phase 11 placeholder
  runtime/             — Layer 2: Simulation runtime [NEW]
    mod.rs             — Exports + future submodule declarations
    context.rs         — SimContext, SimRunMode, SimLifecycle, TimeConfig
    state.rs           — SimStateManager, ContinuousState, DiscreteState
    engine.rs          — SimEngine, SimStepResult, SimSummary
    solver/            — [empty] Phase 3 placeholder
    scheduler/         — [empty] Phase 4-5 placeholder
    workflow/          — [empty] Phase 5 placeholder
    event/             — [empty] Phase 6 placeholder
    multirate/         — [empty] Phase 7 placeholder
    algebraic/         — [empty] Phase 8 placeholder
  blocks/              — Layer 3: Standard block library [empty]
  domains/             — Layer 6: Domain-specific blocks [empty]
  coupling/            — Layer 7a: Multi-physics coupling [empty]
  postproc/            — Layer 7b: Post-processing [empty]
  bindings/            — Layer 7c: Python/plugin bindings [empty]
  db/                  — Layer 5: Database system [empty]
```
